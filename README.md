# 📖 About

**Introduction to Bioinformatics** is an educational repository with Jupyter notebooks that teach the main types of biomedical data used in precision medicine.

The core path has seven lessons: genomic variants, epigenetic marks, RNA expression, proteins, clinical lab tests, wearable signals, and medical images. Two extra folders add large language models in bioinformatics and responsible handling of health data.

Each notebook includes short explanations, sample datasets, and runnable analysis steps so you can learn by doing, not only by reading.

> **Tagline:** *A practical bioinformatics repository, covering genomic, epigenetic, transcriptomic, proteomic, clinical, wearable, and imaging data through interactive Jupyter Notebooks.*

# 🚀 Why This Repository?

Bioinformatics often looks like many separate fields at once.

These notebooks keep the path clear:

- Meet one data type at a time
- See how each dataset is stored and explored
- Run short analyses in Jupyter
- Connect programming, machine learning, and biomedical science

# 📚 Lessons

| # | Notebook | Topics |
|---|----------|--------|
| 1 | [part1_Introduction_to_Genomic_Data.ipynb](part1_Introduction_to_Genomic_Data.ipynb) | Genomics, VCF fields, 1000 Genomes, SNPs, COSMIC and RefGene annotation, variant vs interval annotation |
| 2 | [part2_Introduction_to_Epigenetics.ipynb](part2_Introduction_to_Epigenetics.ipynb) | DNA methylation, histone marks, WGBS, ChIP-Seq, DMRs, NIH Roadmap Epigenomics |
| 3 | [part3_Introduction_to_Transcriptomics.ipynb](part3_Introduction_to_Transcriptomics.ipynb) | Transcriptome, RNA-Seq, bulk vs single-cell, FASTQ / BAM / GTF, DESeq2, heatmaps and volcano plots |
| 4 | [part4_Introduction_to Proteomics.ipynb](part4_Introduction_to%20Proteomics.ipynb) | Proteins and the proteome, mass spectrometry, biomarkers, iPOP abundance data, heatmaps |
| 5 | [part5_Introduction_to_Clinical_Data.ipynb](part5_Introduction_to_Clinical_Data.ipynb) | Clinical lab tests, FPG, OGTT, HbA1C, longitudinal glucose plots |
| 6 | [part6_Introduction_to_Wearable_Data.ipynb](part6_Introduction_to_Wearable_Data.ipynb) | Wearable heart rate and steps, resting heart rate, SQL queries, time-series plots |
| 7 | [part7_Introduction_to_Medical_Imaging.ipynb](part7_Introduction_to_Medical_Imaging.ipynb) | X-ray, CT, MRI, ultrasound, CNN classification of chest X-rays (normal vs pneumonia) |

### Suggested order

1. Start with **Part 1** to understand genomic variants.
2. Continue through **Parts 2–4** for epigenetics, RNA, and proteins.
3. Use **Parts 5–6** for clinical and wearable measurements.
4. Finish the core path with **Part 7** on medical images.
5. Then open the extra folders on LLMs and data privacy.

# ▶️ How to Use

### Option 1 — Open on GitHub

1. Open this repository.
2. Click any `.ipynb` file.
3. Read the cells and review the examples.

### Option 2 — Run locally

```bash
git clone https://github.com/sadra-hatami/Bioinformatics-Training.git
cd Bioinformatics-Training
```

Then install common packages:

```bash
pip install notebook pandas numpy matplotlib seaborn tensorflow
jupyter notebook
```

Some lessons also use R packages such as DESeq2, or cloud tools such as Amazon Athena (`pyathena`). Those parts may need extra setup or an SDO / AWS environment.

### Option 3 — Google Colab

Upload any notebook to [Google Colab](https://colab.research.google.com/) and run the local Python cells in the browser.

Cloud queries and some dataset files may only work in the original Stanford Data Ocean environment.
